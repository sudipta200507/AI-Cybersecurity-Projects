# AI + Cybersecurity Projects

Defensive AI/security engineering projects focused on detection, classification, anomaly analysis and evidence-driven automation.

Projects:
- 01-phishing-url-detection
- 02-network-intrusion-detection
- 03-malicious-message-detection
- 04-web-log-anomaly-detection
- 05-security-event-triage

Clone: `git clone https://github.com/sudipta200507/AI-Cybersecurity-Projects.git`

Projects are designed for authorized defensive analysis. They do not perform unauthorized exploitation, credential theft or destructive actions.

The intrusion project uses the public KDD Cup 1999 intrusion-detection benchmark and the phishing project uses UCI's public Phishing Websites dataset.
